# Reporting a security problem

Please report security problems privately, not in a public issue: this
repository's **Security** tab, **Report a vulnerability**. Only the maintainer
sees it.

Say what you found and how to see it happen. You'll get a reply within a few
days, and a fix is made before the problem is described publicly.

EmberStorm runs on people's own computers at home and holds their photos,
media and passwords, so problems that matter most are ones that let somebody
reach a server they shouldn't, see another person's things on it, or run code
on the computer it runs on.
